# EngiTrace Repository Analyzer Service

## Overview
The Analyzer service is responsible for:
1. **Git Mining**: Parsing Git history, commit messages, author metadata, diffs, and blame ranges.
2. **AST Analysis**: Extracting code syntax trees, function definitions, classes, and cross-file import dependencies using Tree-sitter.
3. **Artifact Linking**: Correlating issue keys, PR titles, and post-mortem logs with code churn.
